# 🛰️ GNSS RINEX Parser & Ionosphere Delay Analysis

Инструментарий на **C++** для извлечения, сортировки и анализа навигационных данных спутниковых систем (GPS / ГЛОНАСС) в форматах **RINEX** и **SP3**. 

Проект разработан в рамках дипломной работы и диссертационного исследования по теме: *«Использование данных с одночастотных приёмников СРНС для оперативной коррекции модели ионосферы»*.

---

## 🎯 Цель и научная новизна проекта

Двухчастотные геодезические приёмники позволяют точно вычислять ионосферную задержку сигнала, но имеют высокую стоимость. Данный проект доказывает возможность оценки вариаций ионосферной задержки с помощью бюджетного одночастотного приёмника (**GlobalSat BU-353**, частота L1, C/A-код).

### Ключевые задачи, решаемые проектом:
1. **Сбор данных.** Запись сырых измерений с одночастотного приёмника (через протокол SiRF binary / SirfTech) и загрузка эталонных данных с базовой станции (станция **IRKL**, Иркутск).
2. **Парсинг и сортировка.** Автоматическая распаковка файлов наблюдений (`RINEX 2.10 / 2.11`) и файлов точных эфемерид (`SP3`) с группировкой псевдодальностей (ПД) и координат (\(X, Y, Z\)) по каждому навигационному спутнику (НС) и эпохам.
3. **Расчёт ионосферной задержки.** Устранение нестабильности шкалы времени приёмника путём построения разности ошибок ионосферы для пары спутников (\(i\) и \(j\)) в один момент времени.

## ⚙️ Подготовка данных и запуск

### 1. Подготовка входных файлов
Перед запуском программы необходимо поместить исходные файлы наблюдений в рабочую директорию:
* `sirfrin1.txt` (или аналогичный RINEX-файл) — данные с одночастотного GPS-приёмника.
* `IRK*` (например, `IRKL1119.txt`) — файлы наблюдений с Иркутской базовой станции.
* `igr*.txt` (формат SP3) — файлы точных эфемерид для расчёта геометрической дальности.

*(Для автоматизации подготовки файлов можно воспользоваться скриптами из директории `scripts/`).*

### 2. Сборка и запуск (Linux / GCC)
Перейдите в директорию с финальной версией проекта, скомпилируйте исходный код и запустите обработку:

```bash
cd Finish
g++ -O2 main.cpp -o rinex_parser
./rinex_parser
```
*(Примечание: если главный файл называется иначе, укажите его актуальное имя при компиляции).*

### 3. Результаты работы
На выходе программа формирует структурированные текстовые файлы (`output.txt` / `out.txt`), где:
* Данные отсортированы по конкретным спутникам (`G1`, `G16`, `R22` и др.) и временным эпохам.
* Отфильтрованы служебные заголовки (до метки `END OF HEADER`).
* Подготовлены матрицы значений псевдодальностей и координат для дальнейшего построения графиков вариаций ионосферы (в Excel или Python).

## 📊 Основные выводы исследования

* В благоприятных условиях (при углах места спутников $\beta > 15^\circ$) погрешность определения разности ионосферных задержек одночастотным приёмником не превышает **1–2 метров** (7 нс) по сравнению с эталонным двухчастотным приёмником.
* При приближении спутника к горизонту ($\beta \approx 5^\circ$) расхождение возрастает до **15–20 метров** из-за неучтённой «влажной» составляющей тропосферы.
* Полученные по предложенному алгоритму данные пригодны для оперативной локальной коррекции модели ионосферы.
